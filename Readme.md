# Weather

A simple, responsive weather app. Search for any city and see the current
temperature, conditions, feels-like temperature, wind speed, and humidity.

## Problem it solves

Checking the weather for a city often means opening a cluttered site full
of ads and unrelated content. This app gives a fast, distraction-free way
to look up current conditions for any city in seconds, with just the
information that matters.

## Features

- Search weather by city name
- Displays temperature, condition, feels-like, wind, and humidity
- Clean, responsive UI
- No API key or backend required — powered by the free [Open-Meteo](https://open-meteo.com/) API

## Tech stack

- HTML
- CSS
- JavaScript (Fetch API, async/await)

## How to run

No build tools or installs needed.

1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in your browser (double-click it, or right-click →
   "Open with" your browser).
